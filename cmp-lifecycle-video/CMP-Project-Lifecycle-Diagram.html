Project lifecycle: request to archive

How a project moves through the Project Register, from the first site request to the archive review. Each step shows who does it and whether it is automated.

Start a project

The project manager asks for a site. The Project Office approves. The flow builds the site and writes the details back to the Register.

Years later. When a project is marked Complete, the clock starts. The weekly check takes over from here.

Close a project

Completed projects are reviewed after two years. The Project Office decides whether to keep or archive each one.
